# Product Overview

## Product Purpose

技術記事と求人情報を RSS で収集し、**「注目されている技術」と「その技術についての記事」をクロスリンクして眺める**個人向けツール。注目の技術と学習リソースが一画面でつながる。

ランキングの軸は当初「求人での言及数」だったが、求人フィードの取得が安定しないため「技術記事での言及数」に切り替えた(2026-07)。求人取得が安定したら、求人言及を重みとして戻す拡張余地を残している(`techRanking` はカテゴリをパラメータ化済み)。

解決する課題:

- 技術トレンドの情報源(はてブ・Zenn・Qiita・HN 等)と求人情報が分断されていて、「いま市場で求められている技術」と「その技術を学ぶための記事」を突き合わせるのに手間がかかる
- 求人票に頻出する技術キーワードを定量的に把握する手段がない(求人軸のランキングは取得安定後に戻す想定。現状は求人一覧の提供のみ)
- 既存の RSS リーダーは記事を時系列に並べるだけで、横断的な集計・クロスリンクができない

副次的な目的として、このプロジェクト自体を **Kafka・Kotlin・Spring Boot の学習題材**にする(就活の文脈でサーバーサイド Kotlin とイベント駆動アーキテクチャの実装経験を積む)。

## Target Users

**主要ユーザー**: 開発者本人(自宅サーバーで運用する個人ツール)

ニーズ:

- 技術系・求人系フィードの新着を 1 箇所に蓄積して見返したい
- 「記事で言及回数の多い注目技術」ランキングと関連記事を一画面で見たい
- フィードの追加は設定ファイルに行を足すだけにしたい

## Key Features

1. **フィード収集**: 技術系フィード(はてブ IT・Zenn・Qiita・Publickey・Hacker News)と求人系フィード(HN Jobs・Who is hiring・We Work Remotely)を定期巡回して蓄積する。フィードは `category = "tech" | "jobs"` の 2 分類
2. **キーワード抽出**: 「正規化名 + エイリアス」の辞書(約 60 分類)+ 正規表現で、タイトル + 概要から技術キーワードを抽出する
3. **クロスリンク(目玉機能)**: 「記事で言及回数の多い注目技術」ランキングと「その技術についての技術記事」を並べて表示する
4. **リアルタイム新着表示**: 取得した新着を SSE でブラウザにリアルタイム配信する
5. **レポート / 集計 API**: 直近 N 日を対象に、①注目技術 × 関連記事のクロスセクション ②技術記事一覧 ③求人一覧 を返す

## Business Objectives

- 就活・学習に直結する技術トレンドの把握を日常のワークフローにする
- Kafka の consumer group・オフセット管理・冪等 sink といった定番パターンを実データで体験する
- サーバーサイド Kotlin(Spring Boot)の実装実績を作る

## MVPスコープ

初回リリース(spec: `mvp-rss-pipeline`)に含めるもの:

- fetcher(RSS 巡回 + キーワード抽出 + Kafka publish)
- sink consumer(DB への冪等書き込み)
- live consumer(SSE 配信)
- レポート / 集計 API + 簡易ブラウザ UI

除外(将来の拡張):

- キーワード抽出の Kafka Streams enricher への切り出し
- 通知(notifier)・全文検索

(MVP 時点では「まず SQLite、PostgreSQL への移行は将来」としていたが、spec `postgres-migration` で PostgreSQL への移行を完了済み)

## Success Metrics

- 定期巡回が自宅サーバーで無人運用できている(systemd 再起動込みで巡回が止まらない)
- 同一エントリの再配信があっても DB に重複が発生しない
- 「注目技術ランキング × 関連記事」が一画面で表示できる

## 制約・既知の課題

- **日本語の求人 RSS はほぼ存在しない**。求人系フィードは当面英語圏中心。日本の求人サイトで RSS を見つけたら設定に追加する
- **求人フィードの取得が安定しない**(Remote OK は HTTP 410 で廃止済み → 設定から削除)。このためランキングは記事言及ベースに切り替えた(上記)
- キーワード辞書はメンテが必要(新しい技術は手で足す)。網羅性より説明可能性を取った意図的な設計
